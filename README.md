# Portfolio_manager

Autonomous investment research repository driven by an equity research agent whose sole
company-analysis source is [Simply Wall St](https://simplywall.st).

## Contents

- [`research/METHODOLOGY.md`](research/METHODOLOGY.md) — screening criteria, quality checks,
  100-point scoring system, ranking categories, and daily update process.
- [`research/WATCHLIST.md`](research/WATCHLIST.md) — ranked high-conviction watchlist
  (living document, updated as new Simply Wall St data becomes available).
- [`research/reports/`](research/reports/) — dated full research reports with complete
  recommendation write-ups.
- [`research/rejected/REJECTED.md`](research/rejected/REJECTED.md) — companies evaluated and
  rejected, with reasons.

## Disclaimer

This repository is an automated research log for personal use. It is not financial advice.
All figures are sourced from Simply Wall St publications and are only as current as the cited
article dates.
